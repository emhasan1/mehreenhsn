# Mehreen Hasan portfolio

Static portfolio published with GitHub Pages from main / root. Message Me uses Web3Forms over HTTPS, collecting name, email, and message. The Web3Forms routing key is intentionally public and cannot read messages. No visitor submissions are stored in this repository or browser storage. The owner email and resume are intentional public portfolio content.

Web3Forms and email providers process submissions under their own policies. Successful API submission does not independently prove inbox receipt.
